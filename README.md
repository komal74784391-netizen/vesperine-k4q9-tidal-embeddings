# Tidal Embeddings: Position-Aware Token Representations for Long Documents

This repository contains the implementation for the paper:

**Tidal Embeddings: Position-Aware Token Representations for Long Documents** (Transactions on Language Systems, 2025)

## What is included

- `src/` -- the full reference implementation used for the experiments
- `configs/` -- configuration files for the reported runs
- `requirements.txt` -- pinned dependencies

## Quick start

```bash
pip install -r requirements.txt
python -m src.train --config configs/base.yaml
```

If you use this code, please cite the paper listed above.
